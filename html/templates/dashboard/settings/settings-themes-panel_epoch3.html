%s

The 13 color variables from the project's Figma file. Applies to every epoch with a color model (1, 2 and 3) - epoch 3 gets these as CSS variables; epoch 1/2 (no CSS custom properties there) get a subset substituted straight into HTML attributes. Epoch -1/0 have no color model, nothing to apply here. Background colors also carry an opacity slider next to the picker (100%% = opaque) - browsers' native color picker has no alpha channel of its own, so this pairs a slider with a live preview swatch instead; opacity only has any visible effect in epoch 3, since epoch 1/2 have no alpha-transparency concept.
